### 🚀 What I Work On

> I build and maintain software systems that are scalable, reliable, and production-ready.

- 💻 **Software Development** — Develop and maintain production systems, keeping API response times under `100ms`.
- 🗄️ **Database Design** — Designed and integrated PostgreSQL + MongoDB architectures matched to application requirements.

- 🤝 **Collaboration** — Work closely with the engineering team on technical decisions, code reviews, and production releases.
